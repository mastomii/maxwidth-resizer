# Privacy Policy

MaxWidth Resizer

Last updated: October 11, 2026

## The short version

This extension collects nothing. It has no servers, makes no network requests,
and contains no analytics or tracking of any kind. Everything it does happens
inside your browser.

## What it saves

To remember your choices, the extension stores:

- which sites you turned it on for
- the maximum width you picked for each of those sites
- the element you selected if you used the manual picker
- your global defaults, like the starting width and theme

This is saved using Chrome's own extension storage, on your computer. It is not
sent anywhere. The extension has no way to send it, because it never makes
network requests.

## What it does not collect

- No browsing history. It reads the current tab's address only to know which
  site's settings to use, and to show the site name in the popup.
- No page content, text, form input, passwords, or files.
- No personal information, identifiers, or device details.
- No analytics, crash reports, or usage statistics.

## Network access

The extension makes no network requests. It loads no remote scripts, styles,
fonts, or images, and it does not run remote code. Everything that runs is code
included in the published package.

## Why it needs each permission

- **storage** saves the settings listed above.
- **scripting** adds the extension to tabs that were already open when you
  installed or updated it, so you don't have to reload the page first.
- **contextMenus** creates the two right-click menu items.
- **Access to http and https sites** lets it work on whichever site you enable.
  On every other site it does nothing.

## Sharing and selling

No data is collected, so none can be sold, shared, or used for advertising,
profiling, or credit decisions.

## Children's privacy

The extension collects no data from anyone, including children.

## Changes

If this policy changes, the new version will be posted at this address with a

## Removing your data

Uninstalling the extension deletes its saved settings. You can also clear them
at any time from the settings page, using "Delete all overrides".
